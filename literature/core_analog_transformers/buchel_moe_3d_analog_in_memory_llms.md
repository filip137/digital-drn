## Summary

This paper studies MoE LLMs on 3D analog in-memory computing hardware. It is
useful for understanding why sparse conditional computation and analog memory
arrays can be complementary, especially when comparing DRN blocks with analog
MoE or MLP acceleration.

- 3D AIMC for LLMs.
